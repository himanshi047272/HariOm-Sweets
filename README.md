
# HariOm Sweets — SugarSprint

A collaborative website development project for HariOm Sweets.

## Project Structure

- `src/` — Application HTML and CSS
- `docs/` — Project and setup documentation

## Prerequisites

- A modern web browser
- Access to the shared GitHub repository

## Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open `src/index.html` in a web browser.

No package installation or build step is required for the current static application.

## Development Workflow

1. Create a feature branch for each Jira story.
2. Make focused changes that satisfy the story's acceptance criteria.
3. Test your changes.
4. Commit and push the branch.
5. Open a pull request for review.
6. Merge after approval.

## Security

- Never commit passwords, API keys, tokens, or private client data.
- Review changed files before opening a pull request.
